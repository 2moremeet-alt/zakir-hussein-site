=====================================================
موقع مركز صيانة ذاكر حسين — دليل الرفع على الاستضافة
=====================================================

الملفات الموجودة في الحزمة:
--------------------------------
- index.html ............ صفحة الموقع الرئيسية (كل حاجة فيها)
- server.js ............. السيرفر (المسؤول عن حفظ التعديلات + رفع الصور للجميع)
- package.json .......... إعدادات تشغيل node (npm start)
- Procfile .............. ملف تشغيل تلقائي لبعض المنصات
- assets/ ............... اللوجو + نسخة اللوحة
- data/ ................. هنا بيتحفظ config.json (إعداداتك) تلقائيًا
- uploads/ .............. الصور اللي هترفعها من اللوحة بتروح هنا تلقائيًا

مهم جدًا: فولدر data و uploads لازم يكون لهم صلاحية كتابة (write) على السيرفر.

=====================================================
الخيار الأول (الأفضل — كل المميزات تشتغل):
استضافة تدعم Node.js
=====================================================

بما إنك عايزة الصور والتعديلات تظهر "للجميع مش محلي"،
الموقع لازم يتشغل بالسيرفر server.js على استضافة تدعم Node.js.
بدونه، الموقع بيشتغل شكليًا بس التعديل والرفع يفضلوا على جهازك أنتِ فقط.

[أ] رفع على Render.com (مجاني — الأسهل):
------------------------------------------
1- سجلي على https://render.com (بإيميل أو جوجل)
2- من لوحة التحكم اضغطي New +  ثم اختاري Web Service
3- هيطلب منك تربطي GitHub: اعمل account على GitHub وارفعي الملفات كلها في ريبو
4- في Render اختاري الريبو، واعبي الحقول كالتالي:
     Name: zakir-hussein-site
     Environment: Node
     Build Command: (اتركيها فاضية أو npm install)
     Start Command: node server.js
5- اضغطي Create Web Service
6- بعد دقيقتين هيديك رابط زي https://zakir-hussein-site.onrender.com
   — ده رابط موقعك الرسمي اللي تبعتيه لأي حد

[ب] رفع على cPanel أو استضافات مشتركة (مثل Hostinger):
-------------------------------------------------------
1- من لوحة تحكم الاستضافة (hPanel/cPanel) ادخلي على File Manager
2- ارفعي محتويات الحزمة (index.html و server.js و package.json و assets)
   في فولدر مثلا اسمه zhsite داخل public_html أو جذر الحساب
3- لو الاستضافة فيها "Node.js Selector" (Hostinger بيوفره):
   - اختاري Node.js version 18 أو 20
   - Application root = /zhsite
   - Application startup file = server.js
   - Application URL = دومينك
   - اضغطي Create ثم Restart
4- لو الاستضافة مش بتدعم Node: كلمي الدعم أو جربي خطة تدعم Node،
   أو روحي للخيار التاني بالأسفل

[ج] رفع على Railway / Vercel:
------------------------------
- Railway: مشروع جديد + New Project + Deploy from GitHub (نفس الملفات) => بيشتغل مباشرة
- Vercel: ممكن مع إعدادات خاصة (لكن Render أسهل لأن Vercel static أصلًا)

=====================================================
الخيار الثاني (بسيط — من غير سيرفر):
استضافة ملفات ثابتة فقط (Static)
=====================================================
ينفع ترفعي index.html + assets فقط على:
- Netlify: اسحبي مجلد الموقع على https://app.netlify.com/drop
- GitHub Pages / أي cPanel static

⚠️ لكن ضعي في بالك: من غير server.js الموقع شكله ومحتواه هيشتغلوا تمام،
لكن "حفظ ونشر للجميع" و"رفع صورة للجميع" مش هيشتغلوا —
اللوحة هتحفظ على متصفحك أنتِ بس وتقولك (⚠️ بدون سيرفر).
يعني الحل الكامل لطلبك (الصور للجميع) = الخيار الأول Node.

=====================================================
بعد ما ترفعي الموقع
=====================================================
- افتحي الرابط، اضغطي 5 مرات على سطر الحقوق (© مركز صيانة ذاكر حسين)
  أسفل الصفحة، اكتبي كلمة المرور 0000، ادخلي لوحة التحكم.
- غيّري كلمة المرور من تبويب "الأمان" أول حاجة.
- جرّبي: عدّلي أي نص أو ارفعي صورة ثم "💾 حفظ ونشر للجميع"
- افتحي الموقع من موبايل تاني/نافذة خفية (Incognito) وهتشوفي التغيير ظاهر
=====================================================

فولدر data و uploads:
---------------------
- data/config.json = كل تعديلاتك على الموقع
- uploads/ = الصور اللي اترفعت من اللوحة
- متحذفيهومش، ولو الاستضافة شالت صلاحية الكتابة أضيفيها
  (chmod 775 أو من File Manager تختاري Permission)
